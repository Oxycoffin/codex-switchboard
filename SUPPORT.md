# Support

Use [GitHub Issues](../../issues) for reproducible bugs and feature requests. Before opening an issue, check existing reports and confirm the problem still occurs on the latest version.

Never attach `auth.json`, cookies, access or refresh tokens, browser profiles, conversation databases, or unredacted screenshots containing account details. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Codex Switchboard is an independent source-available project. It is not an official OpenAI support channel, and maintainers cannot recover or modify OpenAI accounts, subscriptions, usage limits, or billing.
